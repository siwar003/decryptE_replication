Stability/solubility shift setup
SPP/DiffPOP defaults to "Fraction" as the x-axis (no unit). Switch to a thermal / solvent-% subtype only if those are the actual measurement units. The biological interpretation switches accordingly: stabilized-protein peaks shift to higher fractions in DiffPOP, higher temperatures in CETSA.
Stability/solubility profile mapping
Single-file mode — map each intensity column below to its condition and x-axis value. Multiple columns mapped to the same condition × x-level are averaged as replicates and produce error bars.
Multi-file mode — if you upload more than one file (Files tab), this column-mapping list is ignored; each file's condition + fraction is assigned in the per-file table on the Files tab instead.
Map each control/vehicle column to its x-axis value (temperature, solvent %, extraction rank, etc.). Multiple rows with the same x-value are averaged as replicates.
Map each treated column to the same set of x-axis values used for controls.
"Normalized" and "NSAF" both render each protein's profile as a relative abundance distribution that sums to 1 across fractions; NSAF additionally divides by protein length when a length column is present. Log2 imputes ≤2 missing points with a low floor so dips remain visible.
Error bars are drawn whenever ≥2 replicate columns (single-file mode) or ≥2 files (multi-file mode) are mapped to the same condition × x-level. Δpeak = peak_fraction(treated) − peak_fraction(control); leave threshold blank for the subtype default (DiffPOP/SPP = 1.0 fraction, thermal = 2.0 °C, generic = 1.0).
Mode 2 — fit & QC thresholds
A profile with max-min < flat threshold is classified "flat/no response". Jaggedness = sum of |second differences| / range — values above the threshold are flagged "jagged/noisy".
